# I N H E R I T A N C E

การสืบทอดคุณสมบัติจาก Class แม่ไปสู่ Class ลูกทำให้ Class ลูกได้รับ Attribute และ Method ของแม่มาใช้งานได้ทันทีโดยไม่ต้องเขียนโค้ดใหม่ และลูกสามารถเพิ่มความสามารถพิเศษเฉพาะตัวเข้าไปได้

## แนวคิด:
- การสืบทอดแบบลึกๆ (แม่ -> ลูก -> หลาน -> เหลน) จะทำให้ระบบพังง่ายมาก
- Composition over Inheritance เป็นตัวช่วยลดความซับซ้อน แทนที่จะ "สืบทอด" ให้ใช้วิธี "ประกอบร่าง" แทน เช่น แทนที่จะให้ Bird สืบทอดมาจาก Animal เราอาจจะสร้างคลาส Wings แล้วนำไปยัดไว้ใน Bird แทน มันยืดหยุ่นและดูแลรักษาง่ายกว่ามาก
