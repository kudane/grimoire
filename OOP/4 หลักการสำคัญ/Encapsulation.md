# E N C A P S U L A T I O N

การจับเอา Attribute และ Method มารวมกันไว้ใน Class เดียวกันแล้ว "ซ่อน" รายละเอียดข้างในไม่ให้คนภายนอกเข้ามาวุ่นวายโดยตรงได้ใครอยากจะใช้งานต้องทำผ่าน Public Method

## แนวคิด:

- ออกแบบให้โค้ดที่เรียกใช้ Class เราจะต้องไม่พัง เมื่อ Class มีการแก้ไขภายใน
- ระวังการสร้าง Class ที่มีแต่ Attribute Private และมี Getter/Setter ให้ทุกตัว แต่ไม่มี Logic หรือ Method ที่มีความหมายเลย
