# A B S T R A C T I O N

การเอาความซับซ้อน กลไกการทำงานที่ยุ่บยั่บ หรือโค้ดที่เข้าใจยาก ไปเก็บซ่อนไว้เบื้องหลัง เพื่อไม่ให้คนใช้งาน โดยแสดง ฟังก์ชัน ที่จำเป็นต่อการใช้งานจริงๆ เท่านั้นให้เรียกใช้แทน

## แนวคิด

- Abstraction แลกมากับความเข้าใจยากขึ้น จงใช้เมื่อจำเป็น
- Abstraction ซ่อนความซับซ้อนไม่ให้คนใช้ต้องปวดหัว (Abstract/Interface)
