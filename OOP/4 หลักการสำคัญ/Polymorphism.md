# P O L Y M O R P H I S M

(Poly = หลาย, Morph = รูปแบบ) คือความสามารถของ Object ที่ตอบสนองต่อ "คำสั่งเดียวกัน" ด้วย "วิธีการที่แตกต่างกัน" ได้ ขึ้นอยู่กับว่ามันคือ Object ชนิดไหน มักเกิดควบคู่กับการสืบทอด (Inheritance) หรือการใช้ Interface

## แนวคิด
- Switch Case ยาวเหยียด นั่นแปลว่าคุณอาจจะขาด Polymorphism
- ยุคปัจจุบัน เรามักจะทำ Polymorphism ผ่าน Interface มากกว่า Inheritance
