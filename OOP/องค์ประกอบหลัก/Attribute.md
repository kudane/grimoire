# A T T R I B U T E

Field หรือ Property คือตัวแปรที่ฝังอยู่ข้างใน Object มันทำหน้าที่เก็บข้อมูลสถานะ (State) หรือคุณลักษณะต่างๆ ของ Object นั้นๆ พูดง่ายๆ คือมันบอกว่า Object ตัวนี้ "มี" (Has-a) อะไรบ้าง

## แนวคิด:
- Field หรือ Property ข้อมูลพวกนี้คือสิ่งที่บอกว่าแต่ละ Object ต่างกันยังไง
- Getter/Setter เพื่อความปลอดภัย
- ควรออกแบบไปทาง Immutable คือกำหนดค่า Attribute ได้แค่ตอนสร้าง Object (ผ่าน Constructor) แล้วห้ามเปลี่ยนอีกเลย ถ้าจะเปลี่ยนต้องสร้าง Object ใหม่แทน
