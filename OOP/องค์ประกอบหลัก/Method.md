# M E T H O D

ฟังก์ชันที่แฝงตัวอยู่ใน Class มันทำหน้าที่กำหนดพฤติกรรม (Behavior) หรือความสามารถของ Object ว่า Object ตัวนี้ "ทำ" อะไรได้บ้าง และมักจะเป็นตัวจัดการเปลี่ยนค่า Attribute ภายใน Object นั้นๆ

## แนวคิด:
- Method ที่ทำหน้าที่หลายอย่างเกินไป ควรแยกย่อยออกเป็น Method ย่อยๆ
- พยายามหลีกเลี่ยง Method ที่แอบไปเปลี่ยนค่านอกเหนือจากการทำหน้าที่หลักของมัน เช่น อัพเดทลงฐานข้อมูล
