# O B J E C T

ตัวตนจริงๆ ที่ถูกสร้างมาจาก Class มันมีตัวตนอยู่ในหน่วยความจำ (Memory) ระหว่างที่โปรแกรมทำงาน เราสามารถจับต้องมันได้ เรียกใช้มันได้ และมันมีข้อมูลเฉพาะตัวของมันเองที่ไม่เหมือน Object ตัวอื่น (แม้จะสร้างมาจาก Class เดียวกัน)

## แนวคิด:
- Object มี State & Behavior ของพวกมันอยู่ที่เก็บไว้
- Object มี Lifecycle" ของพวกมันอยู่มีเกิดมีดับ
