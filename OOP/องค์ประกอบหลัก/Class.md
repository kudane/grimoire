Class:
"แม่พิมพ์" หรือ "พิมพ์เขียว" (Blueprint) ที่เอาไว้ใช้สร้าง Object (วัตถุ) มันไม่ได้มีตัวตนจริงๆ ให้จับต้องได้ในระบบตอนรันไทม์ (จนกว่าจะถูกสร้างเป็น Object) แต่เป็นตัวกำหนดว่า "สิ่งที่เราจะสร้าง" นั้นจะมีหน้าตาอย่างไร มีข้อมูลอะไรบ้าง และทำอะไรได้บ้าง

แนวคิด:
- การออกแบบ Class สำคัญมาก Class ที่ดีควรทำหน้าที่เดียวให้ดีที่สุด (Single Responsibility Principle)
- การกลับมาแก้โครงสร้าง Class ทีหลังจะเป็นฝันร้าย ดังนั้น คิดเผื่อเรื่องการเปลี่ยนแปลงไว้ตั้งแต่แรก
